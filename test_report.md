# Чек-лист и результаты проверок (Test Report)

| № | Сценарий проверки | Ожидаемый результат | Статус |
|---|-------------------|---------------------|--------|
| 1 | Корректный запрос | Сервис возвращает ответ от модели, статус 200 | Пройдено |
| 2 | Некорректный ввод (пустое поле / >1000 символов) | Возвращается ошибка валидации HTTP 422 | Пройдено |
| 3 | Сбой сети / Недоступность API | Активируется Fallback: "Сервис временно недоступен..." | Пройдено |
| 4 | Повторный идентичный запрос | Ответ возвращается из кеша (`cached: true`, `CACHE HIT` в логах) | Пройдено |
