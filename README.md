# LLM Service

Минимальный устойчивый сервис обработки пользовательских сценариев с использованием БЛМ (LLM).

## Архитектура
1. **API слой (FastAPI)**: Валидация длины сообщений (до 1000 символов).
2. **Cache слой**: Кеширование результатов с TTL по SHA256-хешу параметров.
3. **LLM Client**: Вызов внешней модели с ограничением таймаута (5с), 3 ретраями и Fallback-ответом.
4. **Logging**: Структурированные JSON-логи в консоль и файл `app.log`.

## Быстрый запуск

1. Активировать виртуальное окружение:
```powershell
.\venv\Scripts\Activate.ps1
```

2. Установить зависимости:
```powershell
pip install -r requirements.txt
```

3. Запустить сервис:
```powershell
python main.py
```
